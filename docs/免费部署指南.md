# 免费部署指南：让工作台 24 小时在线

目标：把「AI 运营工作台」部署到免费云服务器，获得一个**永久的公网网址**，手机和电脑随时打开。

项目已内置全部部署配置（Dockerfile / render.yaml / requirements.txt），你不需要懂代码，只需按步骤点鼠标。

---

## 你需要注册的账号（共 2 个，都免费）

1. **GitHub**（github.com）— 用来存放代码
2. **Render**（render.com）— 免费服务器，可用 GitHub 账号直接登录

---

## 第一步：把代码放到 GitHub（约 5 分钟）

1. 登录 github.com → 右上角 **+** → **New repository**
2. 名字填 `drama-ops` → 选 **Private**（私有，别人看不到）→ 点 **Create repository**
3. 在建好的仓库页面点 **uploading an existing file** 链接
4. 把项目的这些文件/文件夹**整个拖进去**（让技术朋友从 `/workspace/channels-drama-ops/` 打包发你，或让 AI 打包成 zip 后解压）：
   - `backend/`、`frontend/`、`requirements.txt`、`Dockerfile`、`render.yaml`
   - ⚠️ **不要**上传 `ops.db`（那是你的本地数据）
5. 拉到底部点绿色按钮 **Commit changes**

## 第二步：在 Render 上一键部署（约 5 分钟）

1. 登录 render.com → 右上角 **New +** → **Web Service**
2. 选 **Build and deploy from a Git repository** → 连接你的 GitHub → 找到 `drama-ops` 仓库 → **Connect**
3. 页面上的设置保持默认即可（它会自动识别 Dockerfile）：
   - Name：随便填，比如 `drama-ops`（这会决定你的网址：`https://drama-ops.onrender.com`）
   - Instance Type：选 **Free**
4. 点 **Deploy Web Service**，等 3~5 分钟，看到 **Live** 绿色字样就成功了
5. 打开你的网址 `https://你填的名字.onrender.com` —— 工作台上线了！

## 第三步：防止免费版休眠（重要！）

Render 免费版 15 分钟没人访问会休眠（再打开要等约 1 分钟）。用免费定时唤醒服务解决：

1. 注册 **cron-job.org**（免费）
2. 新建任务：网址填 `https://你的名字.onrender.com/api/overview`，间隔选 **每 10 分钟**
3. 保存。这样服务器就会 24 小时保持唤醒

## 第四步：装到手机主屏幕

用手机浏览器打开你的 Render 网址 → 点页面上的 **「📲 安装」** 按钮 → 桌面出现「AI运营台」图标，以后点图标直接用。

---

## 数据安全提醒

- 免费服务器**偶尔重启会清空数据**，所以工作台里加了「💾 数据备份」功能（⚙️ 数据接入页底部）
- **每周点一次「⬇️ 下载备份」**，万一数据没了，用旁边的「恢复备份」一键还原

## 备选平台

| 平台 | 特点 | 说明 |
|---|---|---|
| **Render**（推荐） | 免费、稳定 | 按上面步骤，需配 cron-job 防休眠 |
| Koyeb | 免费、不休眠 | 流程类似，New Service → 选 GitHub 仓库 → Dockerfile 自动识别 |
| 自己的云服务器 | 永久、数据不丢 | 把项目传上去后运行：`pip install -r requirements.txt && python -m backend.api.app` |
